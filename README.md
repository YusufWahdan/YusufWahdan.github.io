# YusufWahdan.github.io

Public loader for **DaVinci Control** at https://yusufwahdan.github.io/dvcc/.

This repository contains no data and no application code. The page asks for a username and password, keeps a read-only GitHub token on the device only in encrypted form, and loads the app and its data from a private repository that the token must be allowed to read. Without such a token it shows only the sign-in box.

Source of truth: `08_Tools/control-centre/public/index.html` in the private DaVinci OS repository.
